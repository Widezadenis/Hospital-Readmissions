# Hospital-Readmissions

# Introduction
This projects analyzes Hospital Readmission data to predict which illness is a predictor of hospital readmissions. 

##### Stakeholders:
Chief Medical Officer, Care teams

##### Key Questions: 
What factors preditct hospotal readmissions? 

## Data Overview

##### Source
- [Predicting Hospital Readmissions](https://www.kaggle.com/datasets/dubradave/hospital-readmissions?resource=download)
- Note: This is synthetic/historical data intended for portfolio use and does not contain any Protected Health Information. 

## Data Exploration 
The dataset has 17 columns. 
age - Ages are grouped in brackets for bracket of patient.
time_in_hospital - Days spent in hospital are between 1-14 days
n_lab_procedures - Number of lab procedures are from 1-113
